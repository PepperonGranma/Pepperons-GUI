# Security policy

## Supported version

Security fixes currently target the latest commit on `main`. Pepperon's GUI is
pre-1.0 and does not promise security backports for older installers.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/PepperonGranma/Pepperons-GUI/security/advisories/new).
Private reporting is enabled for this repository. If GitHub does not show the form,
contact the maintainer through their GitHub profile and ask for a private reporting
channel. Do not include secrets, device data, or an unredacted exploit in a public issue.

Include the affected version, impact, reproduction steps, and any safe mitigation.
This is a community-maintained project; response times may vary. Ordinary bugs that
do not have a security impact belong in the public issue tracker.
