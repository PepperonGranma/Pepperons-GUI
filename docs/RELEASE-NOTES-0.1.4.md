# Pepperon's GUI 0.1.4

Pepperon has finished the cable inspection and says this control room is ready.

## Highlights

- Full scrcpy 4.1 command catalog with validated numeric controls and profiles.
- Capability-aware USB and local-network ADB workflows.
- Responsive dark/light themes, custom accents, Highlight controls, and first-run tour.
- Startup animation shown before the main window and strict single-instance behavior.
- Consistent **Start Mirroring** and **Stop Mirroring** session actions.
- Installer shortcuts now use documented Windows Shell COM interfaces through NSIS.
- Expanded bundled-component notices, including Feather MIT attribution.

## Release notes

This is an unsigned Windows x64 pre-1.0 build. Windows may show a publisher or
SmartScreen warning; verify the installer SHA-256 published with this release before
running it. Mirroring and device control stay local. A GitHub request checks the
latest official scrcpy version; downloading a runtime or opening an external link
requires a user action.
